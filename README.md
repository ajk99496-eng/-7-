# 《미해결 수학반: 사라진 7번째 기록》 v3.0 | 인터랙티브 자막 컷신

청람고 기록 시스템에서 문서를 조사하고 Ⅰ. 선택과 배열 단원의 여덟 개 수학 검증을 해결해 사건의 진실까지 밝히는 **완결형 추리 코스웨어**입니다.

## 실행 방법 (Windows PowerShell)

1. ZIP 압축 해제
2. `cheongram-mystery` 폴더에서 터미널 열기
3. 아래를 차례대로 실행

```powershell
npm.cmd install
npm.cmd run dev
```

4. 터미널에 표시된 접속 주소(`http://localhost:5173/` 등)를 브라우저에서 열기

이미 이전 버전을 사용했다면 브라우저에 학습 진행이 남을 수 있습니다. **새 컷신을 처음부터 보고 싶으면 게임 메뉴의 '처음부터 다시 조사'**를 선택하세요. 기존 v2와 저장 키를 공유하므로 이전 진행 기록이 유지됩니다.

## v3에서 추가한 것

- 시네마틱 배경 장면 이미지 13종 (프로젝트 `public/cutscenes/`)
- **프롤로그 4장면**: 발신자 UNKNOWN의 미스터리 소개
- **단서 발견 컷신 12개**: 자료실 문서 전문을 처음 읽고 닫으면 나타나는 짧은 추리 대화 (각 2장면)
- **수학 해설 컷신 8개**: 원순열부터 비둘기집 원리까지 각 3장면
- **최종 엔딩 8장면**: 7번째 연구원, 누락 경위, 발신자 공개 및 사건 종결
- 모든 컷신에 화자 이름, 자막, 단서 정보, **이전 / 다음** 버튼, 장면 수/진행 표시
- 키보드 **← / → / Enter**로 장면 조작
- 단서 문서에서 **'단서 장면 다시 보기'** 제공
- 문서 검증 버튼을 바로 누르면 단서 컷신 후 미션을 시작함
- 프롤로그/단서/해설 컷신은 건너뛸 수 있음. 최종 엔딩은 끝까지 볼 수 있도록 별도 구성

## 진행 구조

1. 익명 조사원 번호로 시작해 **프롤로그 컷신** 보기
2. 내부 자료 검색에서 문서를 선택해 **원문 읽기**
3. 문서를 닫으면 **해당 단서 발견 컷신** 자동 등장
4. 문서의 '이 기록 검증하기' 또는 홈에서 관련 수학 미션 풀기
5. 정답이면 **자막 해설 컷신**을 보고 다음 문서 해금
6. 모두 해결하면 R07 관련 원본 3종을 조사하고 사건 보고서 작성
7. 제출하면 **8장면 최종 엔딩 컷신** 재생

## 단원과 미션

1. 원순열 / 120
2. 염주순열 / 3
3. 중복순열 / 27
4. 같은 것이 있는 순열 / 10
5. 중복조합 / 15
6. 포함배제의 원리 / 21
7. 집합의 분할 / 7
8. 비둘기집의 원리 / 4

문제와 스토리는 창작물입니다. 참고 교과서의 개념에 맞춰 제작했지만 교과서 원문이나 삽화를 복제하지 않았습니다.

## 구현 파일

- `src/App.tsx`: 학습 화면, 문서/미션/컷신 진행 제어
- `src/data/story.ts`: 사건 문서, 학습 문제, 정답, 힌트
- `src/data/cutscenes.ts`: **모든 컷신 화자·자막·컷 구성** (내용 수정 가능)
- `src/styles.css`: UI 및 컷신 레이아웃
- `public/characters`: 원래 제공된 캐릭터 이미지 4장
- `public/cutscenes`: 게임용 합성 이미지 13장
- `tests`: 데이터 구조 및 컷신 연결 자동 검사

## 참고 사항

- 컷신은 **MP4가 아닙니다.** 배경 이미지에 자막과 버튼을 겹쳐 보여주는 인터랙티브 웹 장면입니다. 학생이 직접 다음 장면을 넘깁니다.
- 영상 음성은 포함하지 않았습니다. 화면 텍스트를 읽는 방식입니다.
- 저장/CSV 기능은 브라우저 내부에서 동작하며 서버로 개인정보를 전송하지 않습니다.
- 테스트: 제공된 Node.js 테스트 7개 통과, TypeScript/JSX 구문 검사 통과.
- 이 제작 환경에서는 npm 패키지 다운로드 DNS 오류로 인해 **실제 Vite 빌드 및 브라우저 전체 플레이는 검증하지 못했습니다.** 오류가 보이면 터미널 로그를 공유해 주세요.
